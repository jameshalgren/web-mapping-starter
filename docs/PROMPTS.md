# Starter prompts

Paste your current `index.html` into the AI assistant along with a prompt like:

> This is a MapLibre GL JS starter page with a basemap, a legend panel, and an "About this map"
> panel. Add my GeoJSON file `data.geojson`, loaded with `fetch`, inside the `addMyLayers()`
> function. Style features by [attribute], show a popup with the attributes [name1] and [name2]
> when clicked, fill in the legend panel to match, and write the title, my name, and the data
> source into the "About this map" panel. Return the complete updated `index.html`.

Then check it yourself: Is the layer in the right place? Do the popups show correct values?
Does the legend match the colors? Keep notes on what the AI got wrong. They go in your AI note.
